# 딜리래빗 서비스 소개

딜리래빗 당일배송은 낮에 접수·출고된 물량을 **당일 저녁 시간대(18:00~24:00)에 배송 완료**하는 것을 원칙으로 운영합니다. 배송 전 과정에서 딜리버스가 어떤 기준으로 판단하고 실행하는지 이 가이드에서 확인하실 수 있습니다.

## 운영 시간

| 구분 | 시간 |
|---|---|
| 전체 운영 시간 | 10:00 ~ 26:00 (익일 02:00) |
| 배송 시간대 | 18:00 ~ 24:00 |

## 서비스 운영 원칙

1. **당일 완료 최우선** — 당일 배송 100%를 목표로 운영합니다.
2. **투명한 커뮤니케이션** — 배송 이슈 발생 시 내용을 투명하게 공유하고 D+1 이내 처리를 원칙으로 합니다.
3. **증빙 우선 처리** — 배송 완료 사진, 스캔 로그, 연락 이력을 필수로 남기고 이를 근거로 판단합니다.
4. **데이터 기반 운영** — 관제 시스템으로 실시간 SLA를 관리합니다.
5. **보상·정산 연계** — 이슈 접수 데이터 기반으로 배상 처리를 운영하며 월 정산에 반영합니다.

## 배송 생애주기

주문 접수부터 완료·반송까지의 전체 흐름입니다.

| 단계 | 내용 |
|---|---|
| 1. 주문 접수 · 정보 등록 | 화주사 주문 데이터가 연동되고 수취인 주소·연락처·공동현관 출입정보가 등록됩니다. 이 단계의 정보 정확도가 당일 완료율을 좌우합니다. |
| 2. 출고 · 인계 | 화주사 물량이 딜리버스에 인계됩니다. 미인계(출고 누락) 건은 출고 완료 확인 후 배송으로 전환됩니다. |
| 3. 허브 분류 · 스캔 | 물품 단위로 스캔·분류되어 배송 라우트에 배정됩니다. 분류 완료 시점에 고객에게 배송 시작 알림톡이 자동 발송됩니다. |
| 4. 배송 출발 (18:00~) | 배송 기사가 라우트에 따라 배송을 시작합니다. |
| 5. 배송 시도 | 기본 배송 장소는 문 앞이며, 출입 불가 시 [대응배송 프로세스](/policy/delivery)가 적용됩니다. |
| 6-A. 배송 완료 | 완료 사진을 촬영·등록하고 고객에게 완료 알림톡이 자동 발송됩니다. |
| 6-B. 미배송 → 재배송 | 미완료 처리 즉시 미배송 알림톡이 발송되고, [D+1 재배송 프로세스](/policy/undelivered)로 진행됩니다. |
| 7. 반송 | D+2까지 연락 시도에도 최종 부재·연락 불가인 경우 화주사 공유 후 [반송 처리](/policy/returns)합니다. |
