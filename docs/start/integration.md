# 시스템 연동 안내

## API 연동

- API 연동을 위한 키 발급은 온보딩 과정에서 담당 채널을 통해 요청하실 수 있습니다.
- 주문 정보 전송, 운송장 채번, 배송 상태 수신을 API로 연동할 수 있습니다.

## 배송 상태 수신

딜리버스에서 API를 통해 외부 시스템으로 전달 가능한 배송 상태는 아래와 같습니다.

| 배송 상태 | 시점 |
|---|---|
| 픽업 완료 | 화주사 물량 픽업 완료 |
| 유닛 도착 | 배송 거점(유닛) 도착 |
| 배송 시작 | 배송 출발 |
| 배송 완료 | 배송 완료 처리 |
| 배송 미완료 | 미배송 처리 |

::: info
위 상태 외의 배송 상태가 필요한 경우, 상태 조회 API를 주기적으로 호출(폴링)하여 최신 상태를 확인하는 방식을 권장드립니다.
:::

## 고객 알림톡 연동

배송 상태 알림톡은 별도 발송 마감 시간 없이 **트리거에 따라 자동 발송**됩니다.

| 알림톡 | 발송 시점 |
|---|---|
| 배송 시작 | 허브 분류 완료 시점 |
| 배송 완료 | 배송 기사 업무 완료 시점 (물품 단위) |
| 배송 미완료 | 미배송 처리 즉시 |

- 특정 문구 삽입 또는 **화주사 브랜드명 노출이 가능**합니다. (전체 내용 수정은 별도 개발 협의)
- 최대 글자수는 1,000자입니다.
- 폭설·사고 등 상황별 안내 알림톡 양식을 별도로 운영합니다.

::: warning 주소 데이터 유의사항
등록 주소와 실제 배송지가 다르거나 출입정보가 누락되면 당일 배송이 불가할 수 있습니다. 주문 데이터 전송 시 **주소 정확성과 공동현관 출입정보**를 반드시 확인해 주세요.
:::
