# 입고 · 인수 정책

<span class="policy-meta">시행일: 2026-08-06 · 버전 v1.0</span>

## 인수 기준

- 화주사 물량이 딜리버스에 인계된 시점부터 딜리버스의 배송 책임이 시작됩니다.
- **미인계(출고 누락) 건**은 화주사 귀책으로 분류되며, 출고 완료 확인 후 배송으로 전환됩니다.

## 취급 상품 기준

- 주요 취급 상품의 사이즈·중량 범위는 온보딩 사전 협의 시 확인하며, 계약 조건에 따릅니다.

::: tip 출고 전 수량 검수 권장
일부 상품 누락 건은 대부분 출고 단계 포장 오류에서 발생합니다. **출고 전 수량 검수 프로세스**를 점검하시면 누락 클레임을 예방할 수 있습니다.
:::
