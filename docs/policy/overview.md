본 운영정책은 딜리버스(딜리래빗) 배송 서비스의 운영 전 과정에 대해 **일관된 판단 기준과 실행 절차**를 정의하여, 고객 경험을 보호하고 운영 리스크를 통제하기 위한 문서입니다.

## 문서의 효력과 적용 범위

- 본 가이드는 딜리래빗 배송 서비스의 **공통 운영 기준**을 안내하는 공식 문서입니다.
- 본 정책은 배송 기사, 운송사, 물류 운영 조직을 포함한 딜리래빗 배송 전 과정에 적용됩니다.
- 개별 화주사와의 계약서에 별도 조건이 있는 경우 **계약서가 우선** 적용됩니다. 세부 단가·배상 조건은 계약서를 따릅니다.

## 용어 정의

| 용어 | 정의 |
|---|---|
| 배송 완료 | 지정 배송 장소(기본: 문 앞)에 물품을 전달하고 완료 사진 증빙을 등록한 상태 |
| 미배송 | 당일 배송을 시도했으나 출입 불가·연락 불가 등의 사유로 완료하지 못한 상태 |
| 대응배송 | 정상적인 문 앞 배송이 어려운 경우 지정 우선순위 장소(무인택배함 → 경비실 → 우편함)로 배송하는 것 |
| 반송 | 재배송 시도에도 배송이 불가하여 물품을 화주사 측으로 돌려보내는 것 |
| 귀책 | 배송 이슈의 원인 제공 주체 (딜리버스 / 고객 / 화주사 / 외부 요인) |
| D+n | 최초 배송 시도일(D)로부터 n일차 |

## 정책 개정 원칙

- 정책 변경 시 본 가이드에 반영하고, [정책 개정 이력](/notice/changelog)에 버전·시행일·변경 내용을 기록합니다.
- 화주사 운영에 영향을 주는 변경은 시행 전 담당 채널을 통해 사전 안내드립니다.

::: info 개정 이력
모든 변경 사항은 [정책 개정 이력](/notice/changelog)에서 확인할 수 있습니다.
:::
