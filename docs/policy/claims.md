# 클레임 · 배상 정책

<span class="policy-meta">시행일: 2026-08-06 · 버전 v1.0</span>

## 책임 · 보상 원칙

- **배상 처리 우선** — 귀책 확인 절차로 인해 고객 경험이 저하되지 않도록, 신속한 보상·재배송 처리 후 귀책을 확인합니다.
- **투명한 조사** — 모든 증빙자료를 기반으로 객관적으로 판정합니다.
- **정산 연계** — 귀책 확정 시 계약 기준에 따라 월 정산에 반영합니다.
- **보상 한도** — 일반 상품 50만원, 고가품은 별도 협의합니다.

## 표준 처리 프로세스

1. **사고 접수** — 접수 즉시 처리 티켓 생성
2. **유형 분류** — 오배송 / 스캔누락 / 분실 / 파손 등
3. **증빙 수집** — 완료 사진 / 스캔 로그 / 출고 영상
4. **귀책 판정** — 딜리버스 / 고객 / 화주사 / 외부 요인
5. **손해배상 동의서** — 전자서명
6. **대외 안내** — 화주사 / 고객
7. **정산 반영 및 사례 기록**

## 사고 유형별 표준 대응

| 사고 유형 | 1차 조치 | 증빙 기준 | 처리 목표 | 보상 기준 |
|---|---|---|---|---|
| 오배송 | 즉시 정정배송 | 완료 사진 | 당일 | 정정배송비 없음 |
| 스캔 누락 | 스캔 여부 확인 및 수기 처리 | 스캔 이력 | 당일 | 추가 비용 없음 |
| 분실 | 분실 시점 확인 후 귀책 처리 | 스캔 이력 | D+2 | 계약서 기준 처리 |
| 파손 | 완료 사진 및 출고 영상 분석 | 완료 사진, 출고 영상 | D+2 | 계약서 기준 처리 |
| 도난 | CCTV 확인 후 최종 귀책 판정 | CCTV | D+7 이내 | 계약서 기준 처리 |
| 악천후 | 당일 배송 최우선, 기사 안전 문제 시 익일 전환 및 지연 안내 문자 발송 | 발송 이력 | 최대 익일 | — |

## 유형별 상세 안내

::: details 오배송 · 교차오배송 (처리 목표: 당일)
**발생 상황** — 물품이 인근 주소·타 수령인에게 잘못 전달, 두 수령인의 물품이 서로 바뀌는 교차오배송, 완료 처리 후 고객 미수령 확인

**처리 흐름**
1. 문의 접수 후 배송 정보·완료 사진 확인
2. 배송 기사 오배송 사실 확인 및 정정배송 요청
3. 정정배송 가능 여부·일정 확인 후 고객 안내
4. 불만이 높거나 반복 발생 시 상담원 직접 통화로 에스컬레이션

**화주사 참고** — 정정배송은 당일 즉시 처리를 원칙으로 하며, 정정배송비는 청구되지 않습니다.
:::

::: details 분실 · 도난 (분실 D+2 · 도난 D+7)
**발생 상황** — 완료 후 문 앞·무인 장소에서 제3자에 의해 분실, 배송 과정 중 미확인 분실, 완료 처리 후 고객 미수령

**처리 흐름**
1. 분실 신고 접수 후 송장번호·완료 사진 확인
2. 배송 기사에게 배송 위치·당시 상황 재확인
3. 스캔 이력으로 분실 시점 확인 후 귀책 판정
4. 분실 확정 시 공식 접수 처리 및 배상 절차 안내
5. 분실 후 발견 시 고객에게 위치 안내 및 수령 확인

**화주사 참고** — 도난 의심 건은 CCTV 확인을 거쳐 D+7 이내 최종 귀책을 판정하며, 보상은 계약서 기준으로 처리됩니다. 스캔 누락 단순 건은 스캔 이력 확인 후 당일 수기 처리되며 추가 비용이 없습니다.
:::

::: details 파손 (처리 목표: D+2)
**발생 상황** — 수령 시 물품 파손 확인, 포장 상태 이상으로 내용물 훼손 의심

**처리 흐름**
1. 파손 접수 후 완료 사진 확인
2. 출고 영상 분석으로 파손 시점(출고 전/배송 중) 판정
3. 귀책 확정 후 계약서 기준 보상 처리

**화주사 참고** — 출고 영상이 파손 시점 판정의 핵심 증빙입니다. 보상 한도는 일반 상품 50만원이며, 고가품은 사전 별도 협의를 권장드립니다.
:::

::: details 배송 누락 · 일부 제품 누락 (확인 즉시 처리)
**발생 상황** — 출고 포장 단계에서 일부 상품 누락 채로 배송, 배송 완료 후 수령 물품·주문 내역 불일치 문의

**처리 흐름**
1. 주문 내역·배송 완료 수량 시스템 조회로 누락 확인
2. 누락 확정 시 재배송 일정 안내 또는 환불 절차 진행
3. 포장 단계 오류로 판단되는 경우 화주사에 출고 확인 요청 및 재발 방지 협의

**화주사 참고** — 일부 누락 건 예방을 위해 출고 전 수량 검수 프로세스 점검을 권장드립니다.
:::

::: details 고객 불만 (D+1 이내 처리)
**발생 상황** — 지정 장소가 아닌 임의 장소 배송, 배송 지연·미배송으로 인한 직접 불만 접수, 알림톡 미발송으로 인한 불만

**처리 흐름**
1. 불만 접수 후 배송 기사·시스템 조회로 사실관계 확인
2. 임의 배송 건은 기사 주의 조치 후 재배송 또는 수령 확인 처리
3. 재발 방지 조치 및 후속 처리 결과 고객 안내

**화주사 참고** — 모든 불만 건은 처리 결과가 기록·관리되며, 반복 발생 유형은 재발 방지 조치와 함께 화주사에 공유드립니다.
:::
