# 반품 · 회수 정책

<span class="policy-meta">시행일: 2026-08-07 · 버전 v1.1</span>

## 반품 · 반납의 구분

| 구분 | 정의 |
|---|---|
| 반품 | 고객의 상품 반품 요청 또는 주문 취소로 인한 수거 |
| 반납 | 배송 기사가 미배송 물품을 당일 거점(유닛)에 반납하는 것 |
| 반송 | 재배송 시도에도 배송이 불가하여 물품을 화주사 측으로 돌려보내는 것 |

## 반품 요청 처리

- 반품 요청 접수 후 반품 조건·절차를 안내하며, **화주사 접수 안내 후 익일 처리**를 원칙으로 합니다.
- 미배송 건은 배송 기사에게 반납 사진을 요청해 반납 완료를 확인합니다.
- 재배송 가능 여부 확인 후 일정을 안내하고 결과를 공유합니다.

## 반송 처리 기준

- 딜리버스는 **D(1차)와 D+1(2차)에 걸쳐 총 2회 배송을 시도**합니다.
- D+1에 고객 연락이 불가하거나 부재인 경우 반송이 확정되며, 화주사 공유 후 **다음 회수 간선을 통해 D+2에 반송**됩니다.
- 2차 배송 전 조기 반송이 필요한 건은 D+1 배송 타임 전까지 담당 채널로 요청해 주세요.
- 자세한 재배송 타임라인은 [미배송 판정 · 처리 정책](/policy/undelivered)을 참고하세요.
