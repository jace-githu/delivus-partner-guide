# 미배송 판정 · 처리 정책

<span class="policy-meta">시행일: 2026-08-07 · 버전 v1.1</span>

## 미배송의 정의

당일 배송을 시도했으나 출입 불가·연락 불가·주소 오류 등의 사유로 배송을 완료하지 못한 상태를 말합니다. 미배송 처리 즉시 고객에게 **미배송 알림톡이 자동 발송**되고, 물품은 업무 종료 후 거점에 반납됩니다.

## 처리 타임라인

딜리버스는 **D와 D+1에 걸쳐 총 2회 배송을 시도**합니다. 2회 시도 후에도 배송이 완료되지 않은 물품은 **D+2에 화주사로 반송**됩니다.

| 시점 | 처리 내용 |
|---|---|
| **당일 (D)** | **1차 배송 시도.** 현장에서 대응배송 프로세스 우선 적용 → 대응 장소 없으면 미배송 처리, 미배송 알림톡 발송, 업무 종료 후 거점 반납 |
| **D+1** | 딜리버스 고객센터에서 고객 연락<br>**· 연락 성공** — 출입정보·대응 배송 장소를 확보해 당일 배송 타임에 **2차 배송(재배송) 시도**<br>**· 연락 불가 · 부재** — 반송 확정, 화주사 공유 |
| **D+2** | 2회 시도 후에도 완료되지 않은 물품은 **다음 회수 간선을 통해 화주사로 반송** |

## 주요 발생 원인

- 주문 시 공동현관 출입정보 미기입·오입력
- 등록 주소와 실제 배송지 주소 상이
- 건물 구조상 출입 불가·접근 곤란

## 처리 흐름 (출입정보 · 주소 오류 건)

1. 현장에서 대응배송 프로세스 우선 적용 (고객 연락 → 5분 대기 → 대응 장소 배송)
2. 대응 장소 없을 시 미배송 처리, 미배송 알림톡 즉시 발송 (1차 시도 종료)
3. D+1 고객센터에서 고객 연락, 출입정보·주소 재확인 후 배송 메모 업데이트
4. 정보 확인 완료 시 당일 배송 타임에 2차 배송을 시도하고 결과를 확인
5. D+1에 고객 연락이 불가하거나 부재인 경우 반송 확정 → 화주사 공유 후 D+2 반송

## 귀책 구분 기준

모든 이슈는 증빙자료를 기반으로 귀책 주체를 판정하며, 판정 결과에 따라 아래 처리 방안이 적용됩니다.

| 귀책 주체 | 주요 사유 | 처리 방안 |
|---|---|---|
| 고객 귀책 | 주소 오기입·미기입, 출입정보 미기재, 특수기관 제한, 고객 연락 불가, 지정 수취 장소 미확인 | D+1 고객 연락 후 정보 보강, 당일 2차 배송 시도. D+1 연락 불가·부재 시 반송 전환 (D+2 반송) |
| 딜리버스 귀책 | 기사 사고, 임의 미배송, 스캔 누락, 오분류 | 익일 재배송 및 재발 방지 조치 |
| 화주사 귀책 | 미인계 (출고 누락) | 출고 완료 확인 후 배송 전환 |
| 외부 요인 | 천재지변, 교통통제 | 안전 우선, 대체 일정 협의 |

## 화주사 확인 요청 사항

- 2회 시도 후 **반송이 확정되면 반송 대상 건을 화주사 채널로 공유**드리며, 물품은 D+2에 반송됩니다.
- 미배송 발생 및 재배송 시도 기록은 화주사 채널을 통해 공유됩니다.
- 2차 배송 전 조기 반송이 필요한 건은 D+1 배송 타임 전까지 담당 채널로 요청해 주세요.

::: tip 미배송 예방 — 출입정보 필수 입력
출입정보 미기재로 인한 미배송은 주문 접수 단계에서 **출입정보를 필수 입력**으로 안내하면 크게 예방할 수 있습니다. 주문 페이지 설정 협의를 권장드립니다.
:::
