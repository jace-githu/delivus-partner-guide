# 배송 기준 (당일 · 새벽)

<span class="policy-meta">시행일: 2026-08-06 · 버전 v1.0</span>

## 배송 완료의 정의

- 기본 배송 장소는 **문 앞 배송**입니다.
- 배송 위치가 명확히 확인되도록 **완료 사진(문패·호수·투입 장소 식별)**을 촬영·등록해야 배송 완료로 처리됩니다.
- 고객 협의 없는 임의 배송은 불가합니다.
- 완료 시점에 고객에게 배송 완료 알림톡이 자동 발송됩니다.

## 대응배송 정책

정상적인 문 앞 배송이 어려운 상황(공동현관 출입정보 미기재, 배송 시간대 출입 불가 건물 등)에 적용되는 정책입니다.

### 공통 원칙

- 고객 협의 없이 임의 배송은 불가합니다.
- 공동현관 배송은 분실 우려로 **고객 요청 없이는 불가**합니다. 임의로 공동현관에 배송한 후 분실이 발생하면 배송 파트너 귀책으로 처리됩니다.
- 대응배송 완료 시 배송 위치가 명확히 확인되도록 **촬영 및 앱 내 배송 장소 변경**을 필수로 합니다.
- 지정된 대응배송 장소 외 임의 배송은 불가하며, 대응 가능한 장소가 없는 경우 **미배송 처리**합니다.

### 대응배송 프로세스

| 단계 | 내용 |
|---|---|
| 1. 출입 불가 확인 | 공동현관 비밀번호 미기재, 배송 시간대 출입 불가 건물 등 |
| 2. 고객 연락 | 22시 이전: 전화 연락 또는 세대 호출 / 22시 이후: 문자 발송 |
| 3. 5분 대기 | 연락(발송) 시점 기준 |
| 4-A. 고객 응답 시 | 고객이 원하는 장소에 배송 진행 (단, 주소지 변경 불가) |
| 4-B. 고객 미응답 시 | 아래 대응배송 장소 우선순위에 따라 진행 |
| 5. 대응 장소 없음 | 미배송 처리 → [미배송 프로세스](/policy/undelivered)로 진행 |

### 대응배송 장소 우선순위

1. **무인택배함**
2. **경비실 내부**
3. **우편함 내부**

::: warning 무인택배함 배송 시 필수 사항
앱 내 수취변경 기능을 사용해 **택배함 번호·비밀번호를 정확히 입력**하며, 비밀번호는 **고객 연락처 뒤 4자리**로 설정합니다.
:::

### 단독주택 배송 예외

- 대문 출입 가능 시 문 앞 배송을 진행합니다.
- 유동 인구가 많은 대문 앞은 분실 우려로 배송이 불가하며, 이 경우 **우편함 대응배송만 허용**됩니다.

## 배송 증빙

- 모든 배송 건은 배송 위치 사진을 남기며, 촬영 시 **호수 및 배송 물품이 명확히 보이도록** 촬영합니다.
- 야간에는 플래시 촬영을 권장합니다.
- 앱 사진 촬영이 불가한 배송 건은 배송 위치 사진을 별도 채널로 공유하여 증빙을 유지합니다.

## 악천후 · 불가항력

- 당일 배송을 최우선으로 하되, 배송 기사 안전에 문제가 있는 날씨·지연 사유 발생 시 **최대 익일 배송으로 전환**됩니다.
- 전환 시 고객에게 지연 배송 안내 문자가 발송되며, 폭설·사고 등 상황별 안내 알림톡 양식을 별도 운영합니다.
