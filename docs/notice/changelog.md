| 문서 | 내용 | 시행일 |
|---|---|---|
| 미배송 판정 · 처리 정책 | 배송 시도 횟수를 **D(1차)·D+1(2차) 총 2회**로 명확화. D+1 연락 불가·부재 시 반송 확정, **D+2 화주사 반송**으로 통일 | 2026-08-07 |
| 반품 · 회수 정책 | 반송 시점을 D+2로 통일. 기존 D+3 반송 전 화주사 승인 절차 삭제, 조기 반송 요청 기한을 D+1 배송 타임 전으로 안내 | 2026-08-07 |
| 증빙 · 기록 · 보존 정책 | 문서명을 「개인정보 · 보안 정책」에서 변경. 미확정 상태였던 개인정보 취급 항목 삭제 | 2026-08-07 |
| 클레임 · 배상 정책 | 미확정 상태였던 클레임 접수 기한 항목 삭제 | 2026-08-07 |
