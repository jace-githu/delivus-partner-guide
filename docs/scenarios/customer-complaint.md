# 고객 불만 시나리오

## 발생 상황

지정 장소가 아닌 임의 장소 배송, 배송 지연·미배송으로 인한 직접 불만 접수, 알림톡 미발송으로 인한 불만이 발생한 경우입니다.

## 처리 흐름

1. 불만 접수 후 배송 기사·시스템 조회로 사실관계 확인
2. 임의 배송 건은 기사 주의 조치 후 재배송 또는 수령 확인 처리
3. 재발 방지 조치 및 후속 처리 결과 고객 안내

## 화주사 참고

모든 불만 건은 처리 결과가 기록·관리되며, 반복 발생 유형은 재발 방지 조치와 함께 화주사에 공유드립니다.
