# 오배송 · 교차오배송 시나리오

## 발생 상황

물품이 인근 주소·타 수령인에게 잘못 전달되거나, 두 수령인의 물품이 서로 바뀌는 교차오배송이 발생한 경우입니다. 완료 처리 후 고객 미수령으로 확인되는 경우도 포함합니다.

## 처리 흐름

1. 문의 접수 후 배송 정보·완료 사진 확인
2. 배송 기사 오배송 사실 확인 및 정정배송 요청
3. 정정배송 가능 여부·일정 확인 후 고객 안내
4. 불만이 높거나 반복 발생 시 상담원 직접 통화로 에스컬레이션

## 화주사 참고

정정배송은 당일 즉시 처리를 원칙으로 하며, 정정배송비는 청구되지 않습니다.
