# 배송 누락 · 일부 제품 누락 시나리오

## 발생 상황

출고 포장 단계에서 일부 상품이 누락된 채 배송되거나, 배송 완료 후 수령 물품과 주문 내역이 일치하지 않는 경우입니다.

## 처리 흐름

1. 주문 내역·배송 완료 수량 시스템 조회로 누락 확인
2. 누락 확정 시 재배송 일정 안내 또는 환불 절차 진행
3. 포장 단계 오류로 판단되는 경우 화주사에 출고 확인 요청 및 재발 방지 협의

## 화주사 참고

일부 누락 건 예방을 위해 출고 전 수량 검수 프로세스 점검을 권장드립니다.
