# 분실 · 도난 시나리오

## 발생 상황

완료 후 문 앞·무인 장소에서 제3자에 의해 분실되거나, 배송 과정 중 분실이 확인되지 않는 경우입니다. 완료 처리 후 고객 미수령으로 확인되는 경우도 포함합니다.

## 처리 흐름

1. 분실 신고 접수 후 송장번호·완료 사진 확인
2. 배송 기사에게 배송 위치·당시 상황 재확인
3. 스캔 이력으로 분실 시점 확인 후 귀책 판정
4. 분실 확정 시 공식 접수 처리 및 배상 절차 안내
5. 분실 후 발견 시 고객에게 위치 안내 및 수령 확인

## 화주사 참고

도난 의심 건은 CCTV 확인을 거쳐 D+7 이내 최종 귀책을 판정하며, 보상은 계약서 기준으로 처리됩니다. 스캔 누락 단순 건은 스캔 이력 확인 후 당일 수기 처리되며 추가 비용이 없습니다.
