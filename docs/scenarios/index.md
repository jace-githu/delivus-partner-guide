## 확인 순서

1. 발생한 이슈 유형을 선택합니다.
2. 상황과 필요한 증빙을 확인합니다.
3. 처리 흐름과 화주사 참고사항을 확인합니다.
4. 배상·정산 기준은 [클레임 · 배상 정책](/policy/claims)에서 확인합니다.
