# 문의 채널 안내

## 공식 문의 채널

딜리버스는 **채널톡을 공식 CS 운영 채널**로 사용하고 있습니다.

- 채널톡: [https://delivus.channel.io](https://delivus.channel.io)
- 채널톡 사용이 어려운 경우 계약 시 안내된 실무 채널(Slack 등)로도 소통 가능합니다.

## 운영 시간

| 구분 | 시간 |
|---|---|
| CS 센터 운영 | 10:00 ~ 26:00 (익일 02:00) |

## 상황별 응대 기준

| 상황 | 처리 기준 |
|---|---|
| 주소 변경 | 배송 전/후 여부 확인, **1km 이내만 변경 허용** |
| 반품 요청 | 화주사 접수 안내 후 익일 처리 |
| 분실·오배송 문의 | 증빙 확인 후 귀책 안내, 정정·보상 프로세스 진행 |
| 고객 민감 문의·법적 이슈 | 책임자에게 즉시 이관하여 처리 |

## 문의 시 준비하면 빠른 정보

- 송장번호 (또는 주문번호)
- 발생 일시와 상황 요약
- 관련 증빙 (사진 등, 해당 시)
