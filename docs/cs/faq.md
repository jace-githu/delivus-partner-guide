# 자주 묻는 질문

## 배송 관련

::: details 고객이 배송 주소 변경을 요청하면 어떻게 되나요?
배송 전/후 여부를 확인하며, **기존 주소 기준 1km 이내만 변경을 허용**합니다. 1km를 초과하는 변경 요청은 배송이 어려워, 고객이 주문한 쇼핑몰(화주사)을 통해 반품 신청하도록 안내드립니다.
:::

::: details 공동현관 앞에도 배송해 주나요?
공동현관 배송은 분실 우려로 **고객 요청 없이는 진행하지 않습니다**. 출입이 불가한 경우 고객 연락 후 무인택배함 → 경비실 → 우편함 순의 대응배송 프로세스가 적용됩니다.
:::

::: details 악천후에는 배송이 어떻게 되나요?
당일 배송을 최우선으로 하되, 배송 기사 안전에 문제가 있는 경우 최대 익일 배송으로 전환되며 고객에게 지연 안내 문자가 발송됩니다.
:::

## 미배송 · 반송 관련

::: details 미배송이 발생하면 언제 반송되나요?
딜리버스는 **D(1차)와 D+1(2차), 총 2회 배송을 시도**합니다. D+1에 고객 연락이 불가하거나 부재인 경우 반송이 확정되며, 물품은 다음 회수 간선을 통해 **D+2에 화주사로 반송**됩니다.
:::

::: details 2차 배송 전에 조기 반송도 가능한가요?
고객의 명확한 수령 거부, 주소 오류로 수정이 불가한 경우, 또는 화주사 요청이 있는 경우 2차 배송을 생략하고 조기 반송이 가능합니다. D+1 배송 타임 전까지 담당 채널로 요청해 주세요.
:::

## 클레임 관련

::: details 파손·분실 보상 한도는 어떻게 되나요?
일반 상품은 **50만원 한도**이며, 고가품은 사전 별도 협의를 권장드립니다. 세부 보상 기준은 계약서를 따릅니다.
:::

::: details 오배송이 발생하면 비용이 청구되나요?
정정배송은 당일 즉시 처리를 원칙으로 하며, **정정배송비는 청구되지 않습니다**.
:::

## 알림톡 · 시스템 관련

::: details 알림톡에 우리 브랜드명을 넣을 수 있나요?
특정 문구 삽입 또는 화주사 브랜드명 노출이 가능합니다. 전체 내용 수정은 별도 개발 협의가 필요하며, 최대 글자수는 1,000자입니다.
:::

::: details 알림톡은 언제 발송되나요?
발송 마감 시간 없이 트리거에 따라 자동 발송됩니다. 배송 시작(분류 완료 시점), 배송 완료(기사 업무 완료 시점), 배송 미완료(미배송 처리 즉시) 세 가지가 기본입니다.
:::

## 정산 · 계약 관련

::: details 배상은 정산에 어떻게 반영되나요?
귀책 확정 시 계약 기준에 따라 월 정산에 반영됩니다. 개별 단가·배상 조건은 계약서를 따릅니다.
:::
